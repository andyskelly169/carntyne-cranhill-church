# Carntyne & Cranhill Parish Church website

A responsive static website with a contemporary slate-blue, soft-grey and warm-stone palette.

## Preview locally
Open `index.html` in a modern web browser. An internet connection is needed for Google Fonts, the Church of Scotland logo, the Unsplash photography and the Facebook page plugin.

## Before publishing
1. Open `assets/site.js` and replace `CHURCH_EMAIL` with the church's real email address.
2. The Facebook page is already configured to use: https://www.facebook.com/people/Carntyne-and-Cranhill-Parish-Church/100094600783937/
3. Edit `index.html` to replace the address, email, telephone, Sunday service time and sample notices with confirmed church information.
4. Upload the contents of this folder to your web host.

## Contact form
The form prepares an email in the visitor's email app. It does not store or transmit messages to a server.

## Facebook feed
The page includes Facebook's Page Plugin timeline embed. Facebook may restrict embeds for some page types or browser/privacy settings; the direct Facebook link remains available as a fallback.
